# Todo App

A Next.js (App Router) scaffold for a to-do app - TypeScript + Tailwind CSS.

> Status: starter scaffold from `create-next-app`. The app UI is not built out yet.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Script | Description |
| --- | --- |
| `npm run dev` | Start the dev server |
| `npm run build` | Production build |
| `npm run start` | Serve the production build |
| `npm run lint` | Run ESLint |
